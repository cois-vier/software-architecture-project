Assignment 2: Concrete Architecture

We recovered WezTerm's concrete architecture from its Rust source code at commit 4fbd6b8e9 and compared it with our conceptual architecture in a reflexion analysis. The multiplexer-centred design holds: 12 of the 16 expected dependencies exist in the code. The code is less strictly layered than our model, because configuration, terminal and PTY types are shared by almost every crate, and the git history shows that the main differences were deliberate design decisions. We also analyse the Multiplexer subsystem in depth.
